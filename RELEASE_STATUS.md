# Release status

`v2.1.0-rc1` is a validated local rejection-recovery candidate. The working tree and an independent clean copy each pass the complete release validator with reconstruction enabled.

Merge of the release candidate to the public `main` branch remains blocked until all of the following are complete:

1. A new immutable Zenodo version exists and is opened from a logged-out browser session.
2. The reserved DOI placeholder in `CITATION.cff` is replaced.
3. Authors approve the aggregate clinical release and the manuscript has final ethics, funding, conflicts, and author-contribution text.

Participant-level institutional and linkage data are excluded from this release.
